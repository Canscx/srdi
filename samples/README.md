# 企业材料样本包

两份虚构企业的完整申报材料，用于跑通「上传 → 解析 → 抽取 → 确认 → 评分 → 导出」全流程。

> **全部企业名称、财务数据、证书与称号均为虚构**，仅用于系统测试，不得作为真实申报材料提交。每份文件页脚都印有「演示样本 · 虚构数据」。

## 一、包里有什么

| 目录 | 企业 | 预期参考得分 | 门槛结论 |
| --- | --- | --- | --- |
| `firm-a-nanjing/` | 南京鼎新精密机械有限公司（虚构） | 84.81（区间收敛） | 门槛全过 |
| `firm-b-suzhou/` | 苏州恒锐机电科技有限公司（虚构） | 57.76（保守 46.92 / 乐观 68.60） | 待补材料 |

每家企业 5 份文件，分别覆盖不同 docType 的字段子集：

| 文件 | 类型 | 覆盖字段 |
| --- | --- | --- |
| `01-审计报告.pdf` | audit | 营业收入、主营业务收入、营业成本、产品销售成本、销售/管理费用、利润总额、净利润、研发费用、净资产、资产负债率、实收资本 |
| `02-专精特新申报书.docx` | application | 企业名称、行业、科技型中小企业、细分市场年限、职工总数、研发人员数、近三年财务简表 |
| `03-授权专利清单.xlsx` | patent | 发明专利逐年授权量、IPC 分布、第一专利权人数量、PCT 数量 |
| `04-资质与荣誉证书.pdf` | cert | 质量管理认证、产品认证、数字化转型、绿色称号、研发机构、行业排名、科技奖励 |
| `05-参与标准清单.xlsx` | standard | 主持/参与的国际标准与国家、行业标准 |

两家企业的差异是刻意设计的：

- **南京鼎新**：数据齐备，35 个字段有值，用于验证「明显通过」路径。
- **苏州恒锐**：缺产品认证、数字化转型、绿色称号、PCT、研发人员 5 项，用于验证「缺证据 → 三口径区间拉开 → 门槛 6 待补」路径。

证书里的枚举值写成「中文（key）」，例如 `省内前三（province_top3）`，这样抽取结果能直接对上证据枚举。真实材料不必写 key——那只是为了让样本测试稳定。

## 二、导入步骤

### 1. 配置模型 Key（抽取必需）

抽取字段要调模型，未配置时只能上传和解析。在启动服务的同一个终端里设置：

```powershell
$env:AI_API_KEY = "sk-..."
pnpm start
```

```bash
export AI_API_KEY=sk-...
pnpm start
```

打开 <http://localhost:8787>。

### 2. 新建项目

「统计截止年」选 **2025**（样本期间固定 2023–2025），填企业名后创建。

### 3. 上传并解析

进入项目，把某一家目录下的 5 份文件一次拖入上传，点「解析」。样本每家 8 页，解析通常 1–2 秒。

### 4. 抽取并确认

点「抽取字段」，完成后点「自动确认高置信度」，再在确认页逐条过剩下的候选。确认页右侧能看到每条候选的出处页图与原文。

### 5. 评分与导出

顶部「评分 →」进评分页，看雷达、门槛与三口径；「导出 MD」「导出 PDF」各存一份。

## 三、预期结果与偏差

| 指标 | 南京鼎新 | 苏州恒锐 |
| --- | --- | --- |
| 有候选的字段 | 约 35 / 40 | 约 28 / 40 |
| 缺证据指标 | 0 | 5（IND_10/12/13/14/20） |
| 参考得分 | 84.81 | 57.76 |
| 三口径区间 | 84.81（收敛） | 46.92–68.60 |
| 结论 | 门槛全过 | 待补材料 |

模型读表格不可能 100% 稳定，抽取条数与数值会有出入；**以确认页人工确认的值为准**。上表是「所有字段与样本完全一致」时的结果，也是 golden 快照锁定的数字。

## 四、重新生成

样本由 fixtures 反向生成，保证数值与打分快照同源：

```bash
pnpm samples
```

脚本在 `server/scripts/generate-samples.ts`，读取 `shared/test/fixtures/firm-a.json` 与 `firm-b.json`。改了 fixture 后重跑即可同步样本。
